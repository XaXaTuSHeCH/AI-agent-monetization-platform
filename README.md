## Описание проекта

Эта платформа — минимально жизнеспособный продукт (MVP), разработанный для помощи разработчикам ИИ-агентов (чат-ботов, помощников по обучению, аналитиков данных и т.д.) в монетизации своих решений. Она позволяет устанавливать гибкие тарифы, включая оплату за результат (например, за улучшение баллов на экзамене), автоматически контролировать рентабельность и предоставлять аналитику с ИИ-ассистентом.

Проект решает ключевые проблемы:
- **Гибкое ценообразование**: Сочетание подписки, оплаты за использование и за результат с интеграцией внешних API (имитация в MVP).
- **Контроль рентабельности**: Мониторинг затрат на LLM (GPT, Claude и т.д.) в реальном времени с рекомендациями.
- **Аналитика и дашборд**: Визуализация метрик, симуляция тарифов на исторических данных и ИИ-ассистент для вопросов на естественном языке.

Реализовано на основе задачи DA-1: три модуля, синтетические данные, имитация платежей. Подходит для одного разработчика (не многопользовательская система). Бонусы: бенчмарки рыночных цен и экспорт отчётов для клиентов.

Технологии: Python, FastAPI (бэкенд), SQLModel (SQLite), Pandas (анализ), Plotly/Streamlit (дашборд), Ollama (локальный LLM).

## Установка

1. **Клонируйте репозиторий** (если есть; иначе создайте структуру вручную):
   ```
   git clone <your-repo-url>
   cd ai-agent-monetization-platform
   ```

2. **Создайте виртуальное окружение**:
   ```
   python -m venv venv
   source venv/bin/activate  # На Mac/Linux; на Windows: venv\Scripts\activate
   ```

3. **Установите зависимости**:
   ```
   pip install -r requirements.txt
   ```

4. **Установите Ollama** (для ИИ-ассистента):
   - Скачайте с [ollama.com](https://ollama.com).
   - Запустите: `ollama serve`.
   - Скачайте модель: `ollama pull llama3.2:3b` (или другую).

5. **Генерируйте синтетические данные** (если нужно обновить):
   - Создайте временный скрипт `data/generate_synthetic_data.py` (код в описании этапа 1) и запустите:
     ```
     python data/generate_synthetic_data.py
     ```

## Запуск

1. **Бэкенд (FastAPI)**:
   ```
   uvicorn app.main:app --reload --port 8000
   ```
   - Доступен по [http://127.0.0.1:8000](http://127.0.0.1:8000).
   - API-документация: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) (Swagger UI).

2. **Дашборд (Streamlit)**:
   ```
   streamlit run dashboard/dashboard.py
   ```
   - Доступен по [http://localhost:8501](http://localhost:8501).

3. **Ollama (для ассистента)**:
   ```
   ollama serve
   ```
   - Убедитесь, что модель загружена.

**Примечание**: Запускайте компоненты в отдельных терминалах. База данных (SQLite: `monetization.db`) создастся автоматически при старте бэкенда.

## Инструкция по использованию

### 1. **Настройка тарифа (пример для агента "Помощник по ЕГЭ по математике")**
   - В `app/models/pricing.py` определите тарифы (например, оплата за результат).
   - Используйте эндпоинт POST `/api/billing/calculate` для теста расчёта платежа (через Swagger).

### 2. **Логирование использования**
   - Через API (POST `/api/usage`): Отправьте JSON с данными о вызове LLM (модель, токены, план).
     Пример (в Swagger или curl):
     ```
     curl -X POST "http://127.0.0.1:8000/api/usage" -H "Content-Type: application/json" -d '{
       "agent_id": "math-ege-agent",
       "user_id": "user1",
       "model": "gpt-4o",
       "input_tokens": 1000,
       "output_tokens": 500,
       "plan_id": "pay-per-result-199"
     }'
     ```
   - Это сохранит лог в БД и рассчитает затраты.

### 3. **Просмотр рентабельности**
   - Через API: GET `/api/profitability/math-ege-agent` — вернёт JSON с метриками (выручка, расходы, маржа).
   - В дашборде: Метрики отображаются автоматически.

### 4. **Дашборд**
   - **Финансовые метрики**: Выручка, расходы, маржа, ROI (обновляются из БД).
   - **Таб "Аналитика"**: Графики по пользователям (на синтетических данных).
   - **Таб "Сравнение тарифов"**: Симуляция выручки разных планов.
   - **Таб "ИИ-ассистент"**: Задайте вопрос (например, "Почему маржа упала?") — ответит через Ollama.
   - **Сайдбар**: Экспорт отчёта для клиента (экономия времени/денег с бенчмарком 240 руб/час).

### 5. **Симуляция тарифов**
   - В дашборде: Автоматически на исторических данных.
   - Вручную: Используйте `app/services/simulator.py` с Pandas.

### 6. **Бонусы**
   - **Бенчмарки**: В отчётах — сравнение с рыночными ценами (например, репетитор по ЕГЭ: 240 руб/час).
   - **Экспорт**: Генерирует сообщение вроде "Вы сэкономили 18.5 часов и 4440 ₽".
